메시지 카드 기능 · 사용자가 채워주면 좋은 내용
========================================

현재 넣어둔 것
- 실제 여행 인원 11명
- KE643 / KE644
- Singapore Marriott Tang Plaza Hotel
- 숙박 2026-09-19 ~ 2026-09-24
- 객실 4개
- 예약번호 4개
- 객실 근접 배정 / 일부 Twin / Step Stool / Rollaway Bed / Air Purifier 요청
- 조식 특별가 S$25++
- JUMBO Seafood Riverside Point 9/22 19:00 / 11명 / 6V5D9N

사용자가 확인·추가하면 좋은 내용
1. Marriott Bonvoy 회원 등급
   - 현재 예시 요청에 맞춰 "Platinum Elite"로 넣어둠
   - 실제 등급이 다르면 assets/js/trip-data.js에서 수정

2. Platinum 관련 실제로 묻고 싶은 혜택
   - Suite/Room Upgrade?
   - M Club access?
   - Breakfast benefit?
   - 4PM Late Checkout?
   - 객실 4개 중 혜택 적용 객실 범위?

3. 객실별 세부 배정
   - 어느 예약번호가 어느 가족인지
   - Twin 요청 객실
   - Rollaway 요청 객실
   - Step Stool 요청 객실
   이것까지 있으면 체크인 종합카드를 훨씬 정확하게 만들 수 있음.

4. 공항 → 호텔 단체이동
   - 최종 예약 업체명
   - 차량 종류/대수
   - 기사 연락처
   - 픽업 위치/미팅포인트
   확정 후 "이번 여행" 메시지 카드에 자동 연결 가능

5. 여행 중 자주 보여줄 아이 관련 문구
   - 알레르기
   - 음식 제한
   - 카시트/부스터 필요 여부
   - 유모차 보관
   - 아이가 잠들었을 때 요청

6. 의료/긴급용 정보 중 카드에 넣을 것
   - 여행자보험 연락처
   - 보험사/증권번호
   - 보호자 연락처
   - 복용약/알레르기 등
   민감정보라 웹앱에 넣을 범위는 사용자가 직접 결정 권장

7. 식당 카드
   - 추가 예약 식당이 생기면 예약명/시간/인원/예약번호를 data.js에 추가
   - 음식 알레르기나 피해야 하는 재료가 있으면 별도 카드 가능

구조 원칙
- 팜플렛에는 노출하지 않음.
- 현재는 index → message-cards.html 독립 화면 방식.
- 최종 통합 시 message-cards.js와 trip-data.js는 그대로 재사용 가능.
- 실제 예약정보는 trip-data.js에서만 관리해 카드에 중복 하드코딩하지 않도록 구성.
